# Stock Portfolio Tracker 📈

A simple Python-based Stock Portfolio Tracker that calculates the total investment based on manually defined stock prices and user-entered quantities.

## Features

- Displays available stocks and their prices
- Takes stock name and quantity as input
- Calculates investment for each stock
- Calculates the total investment
- Allows the user to add multiple stocks
- Uses a hardcoded stock price dictionary
- Simple console-based interface

## Technologies Used

- Python
- Dictionary
- While Loop
- If-Else Conditions
- User Input/Output
- Basic Arithmetic
